Predict Loan Amout
Machine Learning Classification Project

## 📌 Overview
This project demonstrates a complete machine learning workflow for classification tasks.  
It covers data preprocessing, handling class imbalance with SMOTE, model training, hyperparameter tuning, and evaluation using multiple metrics.

## 📂 Project Structure
- `practice 2.ipynb` → Main Jupyter Notebook containing the end-to-end workflow.
- `README.md` → Project documentation.

## 🚀 Features
- Data preprocessing (scaling, encoding, imputation)
- Handling class imbalance with **SMOTE**
- Model building with:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - Support Vector Machine (SVM)
  - XGBoost
- Hyperparameter tuning using **GridSearchCV**
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix
  - Classification Report

## 📊 Dataset
- Synthetic dataset used for classification tasks.  
- Preprocessing applied to both numerical and categorical features.

## 🛠️ Technologies Used
- Python 3
- Jupyter Notebook
- Libraries:
  - numpy
  - pandas
  - seaborn, matplotlib
  - scikit-learn
  - imbalanced-learn (SMOTE)
  - xgboost

## 📈 Results
- Multiple models trained and evaluated.  
- Best model selected based on accuracy and F1-score.  
- Hyperparameter tuning improved model performance.
