full description of each plot whether it is right or strong or left swek and having outliers or not
1.age:- -->Almost flat/uniform distribution. -->No skew → data is balanced across age groups.

2.income -->Strong right-skewed distribution. -->Most customers earn below 100,000, only a few with very high income. -->Outliers are higher range.

3.savings -->Also right-skewed. -->Majority of customers have low savings (close to 0–5000). -->A few outliers are having.

4.monthly_expenses -->Right-skewed again. -->Most customers have low to moderate expenses (< 5000). -->Some outliers are exist.

5.num_dependents -->Most customers are at 0, 1, or 2 dependents so the frequency drops sharply after 2 which means long tail on right side (positive skewed). -->Most customers have 0–2 dependents. -->no outliers are lying.

6.credit_score -->Bell-shaped (normal distribution) centered around 600–700. -->Most customers have average credit scores.

7.loan_amount -->Strong right-skew. -->Most loans are small (< 50,000). -->outliers very large loan amounts exist but rare.

8.loan_term_months -->Peaks at certain intervals. -->Loan terms are not continuous.

9.employment_years -->Between 0 and 10 majority of customers are either fresh employees or have only a few years of experience. -->The bars after 15 years are very small.That means only a small fraction of customers have long-term work experience. -->Right skew (positive skew) means the data has a longer tail.

10.recent_default -->no skewness because is a binary variable, it can only take 0 or 1. -->For binary variables, there are no outliers.

11.has_credit_card --> it was completelly similar to recent_default why because it is also a binary variables

12.signup_dayofweek -->Because having 7 bars, one for each day, the bars look almost equal in height → meaning customers signed up fairly evenly across all days. -->It may need encoding method. -->No outliers.

13.debt_to_income -->The distribution is right-skewed, because most customers have low DTI ratios (< 0.5). A few customers have high DTI (> 1.0), meaning debts exceed their income (financially risky). -->and there was some outliers

14.sin_age -->sin_age is a feature-engineered variable created from age. Range: -1 to 1, evenly spread. -->No skewness problem, no outliers.

15.cos_age -->cos_age is a cosine transformation of age. Range: -1 to 1. -->No outliers possible. Used along with sin_age to provide a cyclical representation of age. -->Raw age = directly interpretable (20, 30, 40 years). sin_age + cos_age = abstract, but helps ML models learn periodic or non-linear relationships.

LogiscticRegression:--
# Logistic Regression is a supervised machine learning algorithm used for classification problems, not regression (despite the name).
#It predict the probability that a data point belongs to a particular class.
# The value of Output between 0 and 1, which can be converted into class labels using a threshold (usually 0.5).


2.DecisionTree:--
# A Decision Tree is a supervised machine learning algorithm used for classification and regression.
# It splits the data into branches at different decision points (nodes) based on feature values.
# ARoot node → where the first split happens 
# Internal nodes → further splits
# Leaf nodes → final predictions (class or value)
# At each split, the algorithm chooses the best feature and threshold to separate the data. The "best split" is chosen using impurity measures.
# For classification type Gini Imputer and Entropy.
# For Regression type Mean Squared Error (MSE) or Mean Absolute Error (MAE) to find best splits.


3.SVM:--
# SVM (Support Vector Machine) is a supervised machine learning algorithm used mainly for classification, but it can also do regression.
# It was segritate into 2 catogries which are Linear and Non-linear.
# Linear SVM = Works when data is linearly separable (a straight line can separate classes).
# Non-Linear = When data is not linearly separable, SVM uses kernel trick to project data into higher dimensions.
# Common kernels:1.linear → straight line  2.rbf (Radial Basis Function) → handles complex boundaries  3.poly → polynomial decision boundary.
# Works well with high-dimensional data (many features). Effective even with small datasets.
# This algorithm that finds the best separating boundary.


4.RandomForestClassifier:--
# Random Forest is an ensemble model (many decision trees combined). Works well for both classification and regression.
# It can handle nonlinear relationships and categorical features (after encoding).
# By using GridSearchCV tries different combinations of hyperparameters (like number of trees, depth, split rules) and finds the best performing model.
# your dataset, randomly select subsets of rows (samples) and columns (features), train a Decision tree on each subset and repeatthis process for many trees (e.g., 100 or 500).
# For prediction:
# Each tree votes (predicts a class), random Forest picks the majority vote as the final prediction.
# Works well for both small and large datasets.
# Handles both categorical and numerical features, also handile to outliers and noise.



5.XGBClassifier (Extreame Greadient Boosting):--
# XGBoost stands for Extreme Gradient Boosting. It’s a type of ensemble learning, specifically a boosting algorithm.
# Unlike Random Forest (bagging), boosting builds trees sequentially, each tree learning from the mistakes of the previous ones.
# It may handles missing values automatically and it Can work with heterogeneous data types (numerical + categorical if encoded).
# it Has built-in regularization to prevent overfitting (L1 and L2) it is Very fast and scalable for large datasets.
# And finally Can optimize for different objectives: classification, regression, ranking, etc.


Evaluate using **accuracy, precision, recall, F1-score, confusion matrix**.
